FAQ

Common questions

Do I need pi installed to use Symdy?
Yes. Symdy is a desktop UI for the pi agent framework. You'll need pi installed globally (npm install -g @earendil-works/pi-coding-agent). The app connects to pi in RPC mode automatically.
Is my data private?
Yes. Symdy connects to your local pi instance. No data leaves your machine unless you connect to a remote model provider (which you control). No cloud account, no telemetry.
What's the difference between Free and Premium?
The Free tier is fully functional with persistent memory and all core features. Premium ($5/month) adds priority support, early access to new features, custom memory management, and multi-workspace support — for users who want more control.
How does the memory work?
Symdy (via the Symdy memory system) stores structured facts about you across categories — professional, personal, preferences, projects, and more. Every conversation strengthens its understanding. You can review and manage what's stored.
Is this open source?
The Symdy desktop app source is available on GitHub. The underlying pi agent framework is MIT-licensed open source.
